## 🇬🇧 English

### 📌 Project Overview
This repository contains an academic research project (**Iniciação Científica**) focused on classifying bacterial strains using **Partial Least Squares Discriminant Analysis (PLS-DA)** and Chemometric data analysis techniques in Python. 

The goal is to apply supervised pattern recognition to spectral/analytical data, allowing for precise bacterial discrimination and identification of key biomarker features.

### 🧪 Technical Stack & Libraries
* **Language:** Python (Google Colab / Jupyter Notebook)
* **Data Manipulation:** Pandas, NumPy
* **Chemometrics & ML:** Scikit-Learn, SciPy (PLS-DA modeling, cross-validation)
* **Data Visualization:** Matplotlib, Seaborn

### 📊 Methodology & Pipeline
1. **Data Preprocessing:** Spectral/signal normalization, baseline correction, and noise reduction.
2. **Exploratory Data Analysis (EDA):** Unsupervised dimensionality reduction (PCA) for cluster visualization.
3. **Supervised Modeling (PLS-DA):** Training, hyperparameter tuning (latent variables selection), and cross-validation.
4. **Model Evaluation:** Confusion Matrix, Accuracy, Sensitivity, Specificity, and VIP (Variable Importance in Projection) analysis.
